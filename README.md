# act-generator — генератор актов технической экспертизы

**Русский** · [English](README.en.md)

Внутреннее веб-приложение ТОО «IT Support Group»: выездной специалист входит под своим логином, заполняет форму и получает готовый акт на фирменном бланке (с печатью и подписью) для сохранения в PDF. Каждый акт фиксируется в базе: кто, когда, для какого клиента.

## Стек

Next.js 16 (App Router) · Tailwind CSS 4 + shadcn/ui · SQLite (better-sqlite3) · JWT-сессии (jose) + bcryptjs. PDF — печатная версия бланка через `window.print()` (Cmd/Ctrl+P → «Сохранить как PDF»).

## Возможности

- Авторизация, роли: **специалист** (создаёт акты, видит только свои) и **админ** (видит всё, управляет сотрудниками).
- Форма акта: автономер, дата, клиент, таблица оборудования, описание дефекта, заключение (с шаблоном).
- Печатный бланк 1:1 с фирменным: логотип, печать, подпись (`public/letterhead/`, файлы заменяемые).
- История актов: поиск, фильтры по сотруднику и периоду, точный таймстемп создания; правки фиксируются в `updated_at`.
- Админка сотрудников: добавление, редактирование, смена пароля, отключение; удаление — только без актов (история не теряется).
- У сотрудника два ФИО: обычное (интерфейс) и в творительном падеже — для фразы «акт составлен сервисным специалистом …».

## Локальный запуск

```bash
npm install
npm run dev
```

При первом старте создаётся БД `data/acts.db` и пользователь `admin` — пароль печатается в консоль (или задайте `INITIAL_ADMIN_PASSWORD`).

## Деплой

На сервере нужны Docker и reverse-proxy (например Caddy) с маршрутом на `172.17.0.1:3001`. Реквизиты сервера — в `.deploy.env` (см. `.deploy.env.example`), затем:

```bash
./deploy.sh
```

В каталоге проекта на сервере должен лежать `.env` c `SESSION_SECRET` (генерация: `openssl rand -hex 32`), опционально `INITIAL_ADMIN_PASSWORD`. БД живёт в `data/` (volume) и переживает пересборку. Бэкап: `./backup_db.sh` (cron-совместим).

## Бланк

Компонент `components/ActLetterhead.tsx`. Изображения в `public/letterhead/`: `logo.png`, `seal.png` (печать), `signature.png` (подпись). Для замены достаточно перезаписать PNG (прозрачный фон) и пересобрать: `./deploy.sh`.
